## Что исправлено

Первопричина `ENOENT: assets/icon.ico`: `build` только проверял наличие файла, отдельный генератор искал фото в несуществующем `src/web/`, а ICO/ICNS создавал из старого SVG. Forge использовал другую группу путей. Теперь генератор получает `assets/icons/murz-icon.png`, создаёт все три формата и автоматически вызывается из build и Forge.

Новые тесты удаляют все результирующие иконки во временной копии и запускают настоящий build. Проверяются восстановление, декодирование каждого кадра ICO/ICNS, сохранность исходной фотографии, детерминированность, пропорции/прозрачность для неквадратного PNG и неизменность трея.

Сравнение с базовым коммитом побайтово подтвердило: `src/`, CSS сайта, обработчик hover-анимации, все фотографии/видео сайта, `assets/murz.png` и четыре файла трея не изменены. Масштаб 1.065, сдвиг 20 px и позиционирование видео не менялись.

## Обязательные сценарии таймера

Все сценарии выполняются на управляемых часах, без ожидания реальных минут.

| Сценарий | Покрытие |
| --- | --- |
| Старт работы / уменьшение остатка | `timer.test.ts`: IDLE, полный интервал, дробные задержки |
| Однократное предупреждение за 5 минут | На 55-й минуте из 60; повторные тики/пауза не дублируют |
| Автоматический перерыв / завершение / следующий интервал | Границы 60 и 105 минут, следующий цикл |
| «Прогнать Мурза» | Новый полный Work; повторный и старый intervalId игнорируются |
| Пауза / Resume | Точное сохранение миллисекунд в Work и Break |
| Restart / ручной Break | Полная длительность, снятие только пользовательской паузы |
| Сохранение / восстановление | Настоящий временный каталог, атомарная запись, новый SettingsStore |
| Недопустимые значения | Границы, пустые данные, дроби, NaN/Infinity, warning > work |
| Долгая задержка | Перенос остатка через границы; миллион циклов без replay устаревших состояний |
| Нет параллельных циклов | Управляемый scheduler: Start/Restart/Resume не создают дубликаты; Pause/Stop/dispose очищают |
| Сон / пробуждение | Work и Break, сутки сна, повторные события |

Дополнительно проверены перекрывающиеся sleep/lock в обоих порядках, сохранение пользовательской паузы после wake, предупреждение на границе сна, настройки во время активного/замороженного интервала, отказ записи, конкурентные сохранения и повреждённый JSON.

Тесты интеграции проверяют повторное использование окна, видимость на паузе, меню трея, ограничение IPC правильным окном/frame, тихие уведомления и их fallback, очистку ресурсов при завершении и устаревшие сообщения от предыдущего перерыва. Предыдущие тесты маски, геометрии и неизменности фотографии сохранены.

## Границы подтверждения и действия до выпуска

Нативный DMG, запуск установленного приложения, Gatekeeper, реальные click-through/always-on-top, системный трей в светлой/тёмной теме, сон, блокировка, уведомления, Spaces и физические мониторы требуют проверки на Mac. Сценарии — в [MANUAL-TESTS.md](MANUAL-TESTS.md). Windows и Intel Mac не объявляются поддерживаемыми платформами релиза.

Владелец выполняет нативную сборку/приёмку, браузерные проверки, включает Pages Source = GitHub Actions, проверяет доступность загрузок для посетителя и самостоятельно публикует релиз. Это последующие действия владельца, а не выполненные проверки текущей задачи. Репозиторий приватный; видимость и план GitHub в рамках задачи не менялись.

Сохраняются ограничения v0.1: вертикальная фотография не занимает 65–80% ширины горизонтального монитора без обрезки; macOS alpha hit test асинхронен; по сглаженному контуру возможна погрешность около одного DIP. Фото не перерисовывалось.
