## Обязательные сценарии таймера

Все сценарии выполняются на управляемых часах, без ожидания реальных минут.

| Сценарий | Покрытие |
| --- | --- |
| Старт работы / уменьшение остатка | `timer.test.ts`: IDLE, полный интервал, дробные задержки |
| Однократное предупреждение за 5 минут | На 55-й минуте из 60; повторные тики/пауза не дублируют |
| Автоматический перерыв / завершение / следующий интервал | Границы 60 и 105 минут, следующий цикл |
| «Прогнать Мурза» | Новый полный Work; повторный и старый intervalId игнорируются |
| Пауза / Resume | Точное сохранение миллисекунд в Work и Break |
| Restart / ручной Break | Полная длительность, снятие только пользовательской паузы |
| Сохранение / восстановление | Настоящий временный каталог, атомарная запись, новый SettingsStore |
| Недопустимые значения | Границы, пустые данные, дроби, NaN/Infinity, warning > work |
| Долгая задержка | Перенос остатка через границы; миллион циклов без replay устаревших состояний |
| Нет параллельных циклов | Управляемый scheduler: Start/Restart/Resume не создают дубликаты; Pause/Stop/dispose очищают |
| Сон / пробуждение | Work и Break, сутки сна, повторные события |

Дополнительно проверены перекрывающиеся sleep/lock в обоих порядках, сохранение пользовательской паузы после wake, предупреждение на границе сна, настройки во время активного/замороженного интервала, отказ записи, конкурентные сохранения и повреждённый JSON.

Тесты интеграции проверяют повторное использование окна, видимость на паузе, меню трея, ограничение IPC правильным окном/frame, тихие уведомления и их fallback, очистку ресурсов при завершении и устаревшие сообщения от предыдущего перерыва. Предыдущие тесты маски, геометрии и неизменности фотографии сохранены.

## Границы подтверждения

Состояние проекта: реализованная v0.2 с прошедшими автоматическими проверками и cross-packaging трёх целевых архитектур. Графическая приёмка, native DMG и установочный Windows EXE требуют запуска на целевых хостах. План этой приёмки — [MANUAL-TESTS.md](MANUAL-TESTS.md).

Сохраняются ограничения v0.1: вертикальная фотография не занимает 65–80% ширины горизонтального монитора без обрезки; macOS alpha hit test асинхронен; по сглаженному контуру возможна погрешность около одного DIP. Фото не перерисовывалось для устранения JPEG-каймы.
