# Ручная приёмка MurzHelps v0.2

Этот список — план для настоящих macOS ARM64/Intel и Windows 10/11 x64, а не заявление о выполненной проверке. Результаты текущей среды находятся в VALIDATION.md.

## Быстрый цикл

1. `npm install`, `npm start` из обычной desktop-учётной записи. Кот скрыт, меню показывает Idle.
2. Settings: работа 1, перерыв 1, предупреждение 0. Сохранить, снова открыть и проверить значения.
3. Start Timer. Отсчёт в трее убывает; IDE, браузер и терминал доступны.
4. Через минуту появляется существующий Мурз, `01:00` и заданная фраза. Переключение приложений не скрывает кота.
5. Кот не двигается при перетаскивании, не уменьшается и не исчезает от клика по телу.
6. Через минуту окно автоматически скрывается; начинается новый рабочий интервал `01:00`.
7. Stop Timer останавливает цикл. Подождать минуту: Мурз сам не возвращается.

## Досрочное завершение и команды

1. Start Break Now из Idle, Work и Warning: полный перерыв и один экземпляр окна.
2. Быстро дважды нажать «Прогнать Мурза»: кот исчезает, начинается ровно один полный рабочий интервал. Через несколько секунд он не возвращается.
3. Pause во время работы: время стоит. Resume продолжает остаток.
4. Pause во время перерыва: кот остаётся, видно «Пауза», время стоит. Resume продолжает остаток.
5. «Прогнать Мурза» во время паузы перерыва: начинается новый работающий рабочий интервал.
6. Restart Work Timer из каждой активной фазы: кот скрыт, пользовательская пауза снята, полное время работы.
7. Start Break Now во время перерыва: полный новый перерыв, без второго окна.
8. Закрыть Settings обычной системной кнопкой: основной таймер продолжает работу.
9. Quit MurzHelps из Work, Break и Pause: процесс и значок исчезают, клики снова полностью доступны.

## Предупреждение и настройки

1. Установить 2/1/1, Restart Work Timer. После одной минуты ровно одно тихое предупреждение; кот пока скрыт.
2. Проверить системное уведомление; у неподписанной сборки при ошибке native API — маленькое текстовое окно, исчезающее через 10 секунд. Повторные обновления не создают дубликаты.
3. Установить 1/1/1 и перезапустить работу: предупреждение сразу. При 1/1/0 предупреждения нет.
4. Ввести пустое поле, 0 работы, 241 работы, 121 перерыва, 16 предупреждения, дробь, предупреждение больше работы. Сохранение отклонено с ошибкой поля.
5. Начать двухминутную работу, через 30 секунд сохранить 1/1/0. Остаток старой работы не прыгает; следующий полный рабочий интервал длится минуту.
6. Аналогично изменить длительность во время перерыва и паузы: активный интервал не меняется.
7. Завершить и запустить приложение: настройки сохранены, состояние Idle, старая сессия не возобновлена.

## Сон и блокировка

1. Запустить работу, записать остаток, отправить ноутбук в сон дольше этого остатка. После пробуждения кот не появляется из-за сна; работа продолжается с прежнего остатка (с учётом секунд до фактического сна).
2. Повторить во время перерыва: отдых во сне не заканчивается, после пробуждения остаётся прежнее время.
3. Повторить с блокировкой/разблокировкой экрана там, где ОС предоставляет события.
4. Поставить пользовательскую Pause, заблокировать, отправить в сон, разбудить и разблокировать. Pause сохраняется до Resume.
5. Блокировка и сон могут перекрываться: между пробуждением и разблокировкой отсчёт всё ещё стоит.

## Прозрачность, ввод, мониторы

1. Под котом открыть VS Code с кнопками и выделяемым текстом. Клики через непрозрачное тело не должны активировать элементы. Через прозрачный фон, отверстия и промежуток до панели — должны.
2. Проверить кнопку, таймер и прозрачные закруглённые углы кнопки; непрозрачная панель времени не должна пропускать клики.
3. Проверить быстрые переходы курсора через край кота. На macOS зафиксировать прежнее ограничение асинхронного alpha hit test.
4. Проверить масштаб 100/125/150/200%, Retina, отрицательные координаты второго дисплея, смену основного дисплея и подключение/отключение мониторов.
5. Сделать это и в Break, и при скрытом коте: скрытие должно сохраняться; повторный перерыв использует новую геометрию. Текст и кнопка не перекрывают фотографию.
6. Проверить разные Spaces/виртуальные столы и переключение браузер ↔ IDE ↔ терминал.
7. Mission Control, Dock, панель задач, системное закрытие и диспетчер задач остаются доступны.

## Сборка и smoke

- На каждом целевом хосте: `npm run check`, `npm run make`; установить соответствующий DMG / EXE и повторить быстрый цикл.
- После `npm run build`: `npm run test:smoke`. Скрипт проверяет IDLE, ручной перерыв, dismiss, reuse, ограниченный IPC, симулированный suspend/resume и reflow.
- Smoke не заменяет реальный сон, нативные клики, уведомления ОС и установку приложения.
- Зафиксировать версию ОС, архитектуру, масштаб, тип дисплея и результат каждого раздела.
