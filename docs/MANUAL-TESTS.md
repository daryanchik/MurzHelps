# Приёмка на macOS и Windows

Статус до выполнения: **не проверено на реальных целевых ОС**. Заполнять отдельно для macOS ARM64, macOS Intel и Windows x64; указать версию ОС, разрешение и масштаб.

| Проверка | Действие | Ожидаемый результат |
| --- | --- | --- |
| Первый запуск | `npm install`, `npm start` | Мурз целиком виден, вертикальный, по центру немного ниже середины; фон прозрачен |
| Переключение программ | Открыть VS Code, браузер и терминал; переключать Alt-Tab / Cmd-Tab | Кот остаётся поверх обычных окон |
| Прозрачные участки | Под окном расположить безвредный счётчик кликов; нажать снаружи силуэта и в зазоре возле лапы | Счётчик получает клики |
| Тело | Нажать левой/правой кнопкой и прокрутить колесо над туловищем | Нижнее приложение не получает эти события |
| Контур | Быстро пересекать край шерсти с кликом, особенно на macOS | Зафиксировать возможную гонку переключения пропуска; не считать строгую гарантию доказанной одним успешным кликом |
| Перетаскивание | Тащить туловище/лапу, делать двойной щелчок | Кот не перемещается, не исчезает, не меняет размер |
| Кнопка | Нажать «Прогнать Мурза» | Всё окно немедленно скрывается, нижние приложения доступны |
| Повторный вызов | В меню трея выбрать Summon Murz; повторить 10 раз | Одно окно возвращается на основной монитор, масштаб и маска корректны |
| Второй запуск | Запустить ещё один экземпляр | Появляется существующий кот; второй значок трея не создаётся |
| Масштаб | Windows: 100/125/150/200%; macOS: Retina и внешний дисплей | Контур и кнопка принимают клики в правильных местах, пропорции сохранены |
| Мониторы | Подключить/отключить внешний монитор, сменить основной; повторить при скрытом коте | Видимый кот переезжает на основной экран; скрытый остаётся скрытым до Summon Murz |
| Сон | Усыпить и разбудить компьютер | Состояние видимости сохранено, координаты актуальны |
| Рабочие столы | macOS Spaces и Mission Control; Windows виртуальные рабочие столы | Зафиксировать фактическое поведение; v0.1 не обещает принудительное присутствие на всех виртуальных столах Windows |
| Выход | Quit MurzHelps | Окно, значок трея и процесс исчезают |
| Системное управление | Использовать штатное завершение/Force Quit/Task Manager | Приложение не мешает системному действию и не перезапускается |
| Установщик | На чистом целевом компьютере установить сборку из Actions | Установщик содержит PNG и иконки; задокументировать предупреждения отсутствующей подписи |

Системные защищённые экраны, игры с эксклюзивным fullscreen и глобальная блокировка клавиатуры не входят в область требований прототипа. На macOS есть описанное в README ограничение асинхронного hit-testing. На всех ОС уже начатое другим приложением перетаскивание может сохранять захват мыши.
